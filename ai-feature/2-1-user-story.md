# AF-2-1. 사용자 스토리 (배치 AI 기능)

전체 사용자 스토리는 `../2-1-user-story.md`에서 확인할 수 있다. 여기에는 퀴즈, 차트 해설,
매매 회고와 직접 관련된 항목만 정리한다. 수용 기준과 구현 규칙은 요구사항 문서(`2-2`)에서
다룬다.

## AF-2-1.1 스토리

| ID | 스토리 |
| --- | --- |
| U-Q1 | 학습자로서, 매일 **기초 개념 퀴즈**를 풀며 용어를 익히고 싶다. |
| U-Q2 | 학습자로서, 문제를 풀고 나면 **왜 그게 정답인지 해설**로 이해하고 싶다. |
| U-S1 | 차트를 처음 보는 사용자로서, 차트에 뜬 **신호가 무슨 뜻인지** 해설로 배우고 싶다. |
| U-R1 | 모의 매매를 마친 사용자로서, **결과(손익)가 아니라 내 판단 과정**을 돌아보는 회고를 받고 싶다. |
| U-R2 | 회고를 받는 사용자로서, 지적만 받는 게 아니라 **다음에 뭘 공부하면 되는지**까지 알고 싶다. |
| U-G1 | 모든 사용자로서, AI 콘텐츠에 **"사라", "무조건 오른다" 같은 투자 권유 표현이 없기를** 바란다. |
