# AI-4-4. 평가 — 실험 설계와 실측 근거

> 원 데이터·스크립트: `~/Desktop/sttak/ai-eval/` (레포 밖 보관 — 평가 산출물은 커밋하지 않는다).
> 정리본: 노션 "가드레일 A/B 검수 실측 데이터" · "LLM 검사기·재작성 v2 검증" · "재작성 v3 실험".
> 결정 요약: ADR-032. 여기서는 **평가 방법론과 결론**을 기록한다 — 수치의 단일 출처는 ADR-032.

## AI-4-4.1 평가 원칙

1. **설계 논쟁은 실측으로 끝낸다** — 파이프라인 A/B, 검증기 선택, 프롬프트 조항 하나까지
   데이터로 결정한다. "그럴 것 같다"로 프롬프트를 바꾸지 않는다.
2. **사람 판정을 정답으로** — 경계 문장·오탐 여부의 최종 라벨은 사람이 정한다.
3. **정상 데이터와 위반 유도 데이터를 분리** — 오탐률(정상 보호)과 검출률(위반 차단)은
   서로 다른 실험이다. 하나의 수치로 뭉개지 않는다.
4. **재현성도 측정 대상** — LLM 판정은 확률적이므로 동일 입력 반복 판정으로 흔들림을 잰다.
5. **프롬프트 문구 = 검증된 자산** — 문구 변경은 해당 실측의 무효화다. 재검증 없이 반영 금지.

## AI-4-4.2 실험 설계와 결론

| 실험 | 설계 | 결론 |
| --- | --- | --- |
| 기존 필터 오탐 측정 | 운영 금지어 목록을 정상 1차 생성 834건(판단200·요약200·퀴즈50·차트192·회고192)에 적용 | 68건 오탐(회고 59·차트 9) — 전부 정상 코칭·부정 문맥. 부분 문자열 방식 폐기 근거 |
| 룰 엔진 개선 (4회 진화) | 종결형 매칭 + 예외 4규칙, 오탐 재현 세트 회귀 검증 | 같은 834건 오탐 0, 합성 위반 24/24, 안전 문장 16/16 — 후보 탐지 역할로 채택 |
| 파이프라인 A/B (트랙①②) | A(무조건 재작성)·B(조건부) 둘 다 구현, 정상 150건 + 위반 유도 50건 | 위반 제거는 동률(22/22). A 만 스타일 향상 확보 → 멘토 피드백과 합치해 A 채택, B 는 비용 전환 옵션으로 보존 |
| 재작성 안전성 (150건) | 5기능×30, 원문 대비 전수 분류(동일/향상/동등/회귀) + 라벨 보존 | 향상 5 : 회귀 2(보강 2줄로 차단), 라벨·정답 깨짐 0 — "무조건"이 안전함을 입증 |
| "그대로 출력" 조항 제거 (v3) | 조항 제거판으로 150건 재실행, diff 전수 검토 | 향상≥회귀 유지 — 조항 제거 확정 |
| 검증기 비교 | 정상 250 + 경계 문장 22, 사람 판정 정답. LLM 은 50건×2회 재현성 추가 | 오탐 둘 다 0, 경계문 룰 50% vs LLM 86%, 재현성 뒤집힘 0 — 최종 판정 LLM 확정 |
| 위반 유도 (50건) | 11범주 위반을 프롬프트로 유도 후 파이프라인 통과 측정 | 28건은 1차 생성이 자체 중화, 검출 대상 22건 전건 제거 |
| 주입 방어 (회고) | rationale 에 지시문 24건 주입 | 0/24 뚫림 — [입력 취급] 조항 유효 |
| 뉴스 트랙 분리 스모크 (9/14) | ①기존 분리 산출물 55건 교차 정합(무료) ②운영 구성 재현 100건×2트랙(600호출), Fable 전수 검수 | 교차 모순 0/55·0/100, 잠금 위반·소진 0, 재작성 향상 4:회귀 1 — 분리 반영(PR #53) |

## AI-4-4.3 재검증 절차 (프롬프트 변경 시)

1. `ai-eval/guardrail/` 의 실측 세트 재사용: 판정 정상 250 + 경계 22, 재작성 150, 위반 유도 50.
2. 합격선: 오탐 0 유지 · 경계문 정확도 ≥ 기존(86%) · 향상 ≥ 회귀 · 라벨 깨짐 0.
3. 결과를 노션 검수 페이지에 추가하고, 문안 교체 커밋에 실측 링크를 남긴다.
