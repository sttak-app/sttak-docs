# AF-3-2. AI 호출 계약 (배치 AI 기능)

각 AI 호출이 어떤 값을 받고 무엇을 반환해야 하는지 계약으로 정의한다. 스키마 강제,
재생성만 자유 텍스트로 처리, 코드 잠금, 검증 전 결과 사용 금지 등의 설계 원칙과 공통 검증
호출(재생성·검수)은 `../ai-chatbot/3-2-contract.md`를 따른다. 세 기능은 모두 구현이 끝났으며,
아래 출력 JSON이 실제 계약이다. 🔒 표시는 코드로 잠그는 값이다. 입력 예시는 프롬프트에
포함되는 내용을 설명하기 위한 것으로, 실제 전송 형식이나 필드명을 뜻하지 않는다.

## AF-3-2.1 퀴즈 생성

입력: 별도 원본 데이터 없이 주제 범위만 지정한 프롬프트

```text
기초 개념(용어·정의·원리) 범위에서 4지선다 퀴즈 10문항을 생성하라.
시황·전망·특정 종목 언급 금지. 예시 주제에 갇히지 말 것.
```

출력:

```json
{
  "quizzes": [
    {
      "content": "분산투자에 대한 설명으로 가장 알맞은 것은?",
      "choiceA": "한 종목에 자금을 집중하는 것",
      "choiceB": "여러 자산에 자금을 나누어 투자하는 것",
      "choiceC": "매일 주식을 사고파는 것",
      "choiceD": "대출을 받아 투자 금액을 늘리는 것",
      "correctChoice": 2,
      "explanation": "분산투자는 위험을 줄이기 위해 여러 자산에 자금을 나누어 투자하는 방법이에요. 한 종목에 집중하는 방식과는 달라요."
    }
  ]
}
```

`correctChoice`는 1부터 4까지의 정수이며, 재생성 과정에서 바뀌지 않도록 코드로 잠근다.

문항을 생성한 뒤에는 유사도 비교를 위해 문항 텍스트를 임베딩한다. 생성된 벡터를 기존 문항
벡터와 비교하고, 의미가 겹치면 해당 문항을 폐기한다.

## AF-3-2.2 차트 신호 해설

입력: 신호 종류 + 종목 + 발생 시점 + 고정 설명문

```json
{
  "signalType": "GOLDEN_CROSS",
  "stockName": "삼성전자",
  "occurredAt": "2026-09-19",
  "fixedDescription": "5일 이동평균선이 20일 이동평균선을 상향 돌파"
}
```

출력:

```json
{ "explanation": "골든크로스는 5일 평균선이 20일 평균선을 … (4~5문장)" }
```

- 결과에 맞춘 해설이 생성되지 않도록 신호 발생 후의 실제 주가 방향은 **입력에 넣지 않는다**.

## AF-3-2.3 매매 회고

입력: 매매 정보(종목·가격·손익) + 매매 근거 rationale (주입 방어 처리)

```json
{
  "stockName": "삼성전자",
  "buyPrice": 71000, "sellPrice": 74500, "profitRate": 4.9,
  "rationale": "실적 발표 보고 샀고, 목표가 도달해서 팔았다"
}
```

출력:

```json
{
  "summaryLine": "매매 근거와 매도 기준이 구체적이었어요.",
  "goodPoints": [
    "확인할 수 있는 실적 발표를 매수 근거로 삼았어요.",
    "미리 정한 목표가에 도달했을 때 매도했어요."
  ],
  "watchPoints": [
    "실적 발표에서 어떤 지표를 중요하게 봤는지 기록해 보세요. (학습 주제: 기업 실적 읽기)"
  ],
  "evaluations": [
    {
      "type": "GOOD",
      "content": "확인할 수 있는 사실과 매도 기준이 근거에 담겨 있어요."
    }
  ]
}
```

`evaluations.type`은 `GOOD`, `BAD`, `IMPROVEMENT` 중 하나다. 재생성 과정에서
`evaluations`의 개수와 `type` 순서가 바뀌지 않도록 코드로 잠근다.

## AF-3-2.4 공통 검증 호출

재생성(자유 텍스트)과 검수(`pass`/`violations` JSON)는 모든 기능이 함께 사용한다. 자세한
계약은 `../ai-chatbot/3-2-contract.md §CB-3-2.4`를 참고한다.

## AF-3-2.5 코드 잠금 값

| 기능 | 잠금 값 | 바뀌면 |
| --- | --- | --- |
| 퀴즈 | 문항별 `correctChoice` | 해당 문항 반려. 정답 번호가 바뀌면 오답이 정답으로 처리될 수 있음 |
| 회고 | `evaluations` 개수 + `type` 시퀀스 | 해당 회고 반려 |
| 차트 해설 | 구조화 값 없음(단문 텍스트) | 형식 규칙과 검수만 적용 |
