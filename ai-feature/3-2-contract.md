# AI-3-2. 계약 — 입출력 불변 · 코드 잠금 · 폴백

> API 시그니처/응답 포맷 전체는 `../3-3-contract.md` 와 `docs/iosapi/apidocs.md` 가 원본.
> 여기서는 AI 기능이 **백엔드의 나머지 부분·iOS 와 맺는 약속**을 정의한다.

## AI-3-2.1 대원칙 — 파이프라인은 계약을 바꾸지 않는다

가드레일 파이프라인(ADR-032)은 저장 전 단계에서만 동작한다. 따라서:

- **API 응답 스키마 무변경** — iOS 는 파이프라인 도입 전후를 구분할 수 없다.
- **DB 스키마 무변경** — 마이그레이션 없음.
- 가드레일 정책 변경(범주 추가·프롬프트 수정)도 계약에 영향을 주지 않아야 한다.
  계약에 닿는 변경(필드 추가 등)은 `../3-3-contract.md §3-3.14` 절차를 따른다.

## AI-3-2.2 코드 잠금 — 재작성이 못 건드리는 값

재작성은 "표현"만 다듬는다. 아래 구조화 값이 바뀌면 어댑터가 반려한다(생성 실패 처리):

| 기능 | 잠금 값 | 검증 방식 | 근거 |
| --- | --- | --- | --- |
| 뉴스 판단 | perStock 각 항목의 `stockCode` + `sentiment` | 원본 ↔ 재작성본 항목별 동등성 (`requireSameSentiments`) | 감성 라벨은 판정 그 자체 — 표현 정제가 판정을 바꾸면 데이터 오염 |
| 뉴스 요약 | (구조화 값 없음 — 텍스트 4필드) | 형식 슬롯(길이 규격) + 판정만 | — |
| 퀴즈 | `correctChoice` (문항별) | 인덱스별 동일성 (`requireSameAnswers`) | 정답 번호가 바뀌면 오답을 정답 처리 |
| 회고 | `evaluations` 개수 + `type` 시퀀스 | 순서 포함 동등성 (`requireSameEvaluations`) | strict 스키마는 1차 생성에만 걸림 — 재작성 경로는 코드로 잠근다 |
| 차트 | (구조화 값 없음 — 단문 텍스트) | 형식 슬롯 + 판정만 | — |

## AI-3-2.3 실패·폴백 계약

"실패해도 기능·배치는 산다"가 계약이다. 소진/반려 시 저장하지 않고:

| 기능 | 폴백 | 사용자에게 보이는 것 | 예외 타입 |
| --- | --- | --- | --- |
| 뉴스 요약·판단 | 상태 유지 → 다음 회차 재시도 (트랙은 분리돼도 실패는 기사 단위 — 부분 성공 없음) | 해당 기사만 가공 전 상태 | `NewsException.NEWS_ANALYSIS_FAILED` |
| 퀴즈 | 해당 문항 폐기 → 재시도(최대 3회) | 그 회차 퀴즈 수가 줄 수 있음 | `QuizException.QUIZ_GENERATION_FAILED` |
| 차트 해설 | 저장 안 함 → 다음 배치 재생성 | `explanation: null` → iOS 정적 카피 표시 | `ChartException.EXPLANATION_GENERATION_FAILED` |
| 회고 | 저장 안 함 → 다음 정산 배치 재생성 | 회고 미표시(대기) | `TradeException.REVIEW_GENERATION_FAILED` |

- 흡수 범위는 Exception 계열 — Error(OOM)·프레임워크 장애는 잡을 실패시킨다(경보 정당).
- 개별 실패가 잡·스텝·다른 건의 처리를 중단시키지 않는다 (건별 REQUIRES_NEW / 건별 catch).

## AI-3-2.4 판정 불능의 방향 (fail-open 경계)

| 상황 | 처리 | 이유 |
| --- | --- | --- |
| 판정 호출 실패·응답 없음·파싱 실패 | **통과** (fail-open) | 실측 오탐 0/250의 "확신 없으면 통과" 원칙 — 판정 장애로 정상 콘텐츠를 막는 피해가 더 큼 |
| 판정 모델 refusal (응답 거부) | **반려** (fail-closed) | 확신 없음이 아니라 입력 이상 신호. 재작성 루프 경유, 지속 시 소진→폴백 |
| 재작성 호출 실패 | 원문 유지 후 판정으로 | 판정이 최종 저지선 |

이중 fail-open 겹침(재작성 실패 + 판정 refusal)으로 무검수 원문이 저장되는 경로는 refusal
반려가 차단한다.

## AI-3-2.5 AI 생성 표시·책임 한계 (iOS 와의 약속)

- AI 생성 콘텐츠임을 화면에 표시하는 것은 iOS 책임, 추천성 표현이 없음을 보장하는 것은
  서버 가드레일 책임 (apidocs §755, §1012).
- 차트 해설은 350자 이내 전문을 내려보낸다 — iOS 는 자르지 않고 전문 렌더링(확인 완료).
- 모델명(`modelName`)은 저장하되 iOS 계약에는 포함하지 않는다 (내부 추적용).
