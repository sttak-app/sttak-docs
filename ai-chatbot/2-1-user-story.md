# CB-2-1. 사용자 스토리 (챗봇 + 뉴스 AI)

## CB-2-1.1 뉴스 AI

| ID | 스토리 |
| --- | --- |
| U-N1 | 초보 투자자로서, 어려운 뉴스 기사를 **내 눈높이의 제목·한 줄·상세 요약**으로 읽고 싶다. |
| U-N2 | 초보 투자자로서, 기사에 나온 **어려운 용어의 풀이**를 그 자리에서 보고 싶다. |
| U-N3 | 관심 종목 보유자로서, 이 뉴스가 **내 종목에 호재인지 악재인지와 그 이유**를 알고 싶다. |

## CB-2-1.2 챗봇

| ID | 스토리 |
| --- | --- |
| U-C1 | 뉴스를 읽다가 **"이게 왜 호재야?"**를 그 자리에서 바로 물어보고 싶다. |
| U-C2 | **"PER이 뭐야"** 같은 용어 질문에 정확한 풀이를 받고 싶다. |
| U-C3 | **"삼성전자 관련해서 무슨 일 있었어?"**처럼 내 종목 기준으로 묻고 싶다. |
| U-C4 | 기사에서 본 **표현 그대로** 물어도("유상증자 발표했다던데") 그 기사를 찾아 답해주면 좋겠다. |
| U-C5 | 답변이 **어디서 나온 얘기인지(출처)** 확인하고 싶다. |
| U-C6 | 질문하면 **오래 기다리지 않고** 답을 받고 싶다. |

## CB-2-1.3 공통

| ID | 스토리 |
| --- | --- |
| U-G1 | 모든 사용자로서, AI 콘텐츠에 **"사라", "무조건 오른다" 같은 투자 권유 표현이 없기를** 바란다. |
