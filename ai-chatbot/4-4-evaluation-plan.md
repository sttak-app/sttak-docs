# CB-4-4. 평가 계획 (결정 항목 카탈로그)

> 원칙: 설계 논쟁은 실측으로 끝낸다 (`../ai-feature/4-4` 준용). **평가셋이 구현보다 먼저다** —
> §4-1~4-3 의 ❓ 대부분이 여기서 답을 얻는다.

## CB-4-4.1 검색 평가셋 — 만들 것

- ❓ 규모·구성: 질문 → 정답 청크(사람 라벨) 세트. 유형 커버 필수:
  ① 사건 질문("무슨 일이야") ② 종목 영향 질문("왜 호재야") ③ 용어 질문("PER?")
  ④ **기사 표현 그대로 질문**("유상증자 발표했다던데" — BM25 이득 검증용)
  ⑤ 정답 없는 질문(0건 폴백·저근거 행동 검증용)
- 지표: 검색 실패율(정답 청크가 top-N 에 없는 비율), MRR/recall@k 류 ❓택1
- 라벨링: Fable 수행(기존 평가 방식) + 사람 검수

## CB-4-4.2 실험 매트릭스 — 돌릴 것

| 축 | 비교 | 답하는 질문 |
| --- | --- | --- |
| 저장소 | 현행 pgvector vs ES 하이브리드 vs ES+컨텍스추얼 (3단) | 전환·컨텍스추얼 각각의 근거 |
| 청크 분할 | 1기사 1청크 vs 요약+종목판단 분리 | §CB-4-1.1 |
| 임베딩 | small vs large | §CB-4-1.4 (비용 2배의 근거) |
| rerank | 유 vs 무 (품질 + p95 지연 동시 측정) | §CB-4-2.3 |
| 파라미터 | k, RRF k, top-N | §CB-4-2.2 |

전 조합 격자 아님 — 저장소 축 확정 후 나머지를 순차로 (교락 방지).

## CB-4-4.3 답변 품질·가드레일 평가 — 만들 것

- ❓ 답변 루브릭 (근거 충실·환각·출처 정확·톤) — 기존 기능 평가 루브릭 준용해 챗봇판 작성
- ❓ 챗봇용 위반 유도 세트 — §CB-4-3.2 (c)안의 위반율 실측용 (배치 실측 834건=위반 0 은
  배치 프롬프트 기준이라 챗봇 프롬프트로 재실측 필요)
- 지연: 시나리오별 p95 (검색만 / +rerank / 첫 토큰까지) — C-NFR1 예산 검증
